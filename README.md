# Odin Calculator

Calculator project for The Odin Project's Foundations course, built with HTML,
CSS and JavaScript.

## Features

- Digits, decimal point and the four basic operations
- Chained operations are worked out one pair at a time, so `12 + 7 - 5 * 3 =`
  gives 42
- Pressing two operators in a row replaces the first one
- Dividing by zero shows a message instead of breaking
- Long results are rounded so they fit on the display
- `C` clears everything and `⌫` deletes the last digit
- Keyboard support: digits, `.`, `+ - * /`, `Enter` or `=`, `Backspace`, and
  `Esc` or `c` to clear
